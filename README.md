# Reabilita — Meu joelho

Aplicativo web responsivo para organizar a rotina de reabilitação enviada nas imagens.

## Tecnologias
- HTML, CSS e JavaScript puro (sem React e sem dependências).
- `localStorage` para manter registros no próprio aparelho.
- PWA básico para permitir instalação na tela inicial e cache offline após a primeira abertura.

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador para testar (alguns recursos PWA exigem hospedagem HTTPS).
3. Para usar no celular e instalar como aplicativo, publique a pasta em um serviço estático com HTTPS, como GitHub Pages, Netlify ou Vercel.
4. No celular, abra o endereço no navegador e escolha **Adicionar à Tela de Início**.

## O que está incluído
- Treino 1 — Academia A: 6 exercícios.
- Treino 2 — Academia B: 6 exercícios.
- Treino 3 — Casa e grama: 7 exercícios.
- Agenda semanal conforme a rotina compartilhada.
- Marcação dos exercícios e conclusão dos treinos.
- Histórico de treinos e registro diário de desconforto/inchaço.
- Dados armazenados localmente no navegador do aparelho.

## Importante
O app apenas organiza as orientações que você compartilhou. Não prescreve progressões, cargas ou liberação para corrida, saltos ou futebol. Confirme a rotina com seu fisioterapeuta. Os registros ficam no armazenamento local do navegador; limpar os dados do navegador pode apagá-los.
